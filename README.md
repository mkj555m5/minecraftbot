# بوت تلجرام لماين كرافت (Player Bot)

بوت تلجرام يتحكم في بوت ماين كرافت (Player Bot) يدخل السيرفر ويبقى لفترة محددة.

## المميزات
- الاتصال بأي سيرفر ماين كرافت (Java Edition)
- تحديد إصدار اللعبة تلقائياً أو يدوياً
- ضبط مدة الاتصال (ساعة، 10 ساعات، أو مخصص)
- استقبال رسائل الدردشة في التلجرام
- أوامر بسيطة وسهلة

## التثبيت المحلي
1. تثبيت Node.js (الإصدار 16 أو أحدث)
2. إنشاء بوت تلجرام عبر @BotFather والحصول على التوكن
3. نسخ `.env.example` إلى `.env` ووضع التوكن
4. تثبيت المكتبات: `npm install`
5. تشغيل البوت: `npm start`

## النشر على الاستضافة (Hosting)
### متطلبات الاستضافة:
- دعم Node.js
- إمكانية تعيين متغيرات البيئة

### خطوات النشر:
1. ارفع مجلد `bot` إلى الاستضافة
2. قم بتثبيت المكتبات: `npm install`
3. أضف متغير البيئة `TELEGRAM_BOT_TOKEN` مع التوكن الخاص بك
4. شغل البوت باستخدام `npm start` أو عبر مدير العمليات (PM2)

### نصائح للاستضافة المجانية:
- **Railway**: ارفع الكود على GitHub واربطه بـ Railway
- **Render**: ارفع الكود واختر Web Service
- **Heroku**: استخدم `Procfile` (أنشئ ملف `Procfile` يحتوي على `worker: npm start`)

## الأوامر
- `/start` - بدء التشغيل
- `/connect <ip> <port> [version] [duration]` - الاتصال بالسيرفر
  - مثال: `/connect play.hypixel.net 25565 1.16.5 60`
  - المدة بالدقائق: 60 (ساعة), 600 (10 ساعات)
- `/disconnect` - قطع الاتصال
- `/status` - حالة البوت
- `/help` - عرض الأوامر

## ملاحظات
- البوت يستخدم إصدار `minecraft-protocol` 1.26.13.1 (متوافق مع إصدارات ماين كرافت الحديثة)
- يمكنك تحديد إصدار ماين كرافت في أمر `/connect` (مثل 1.16.5, 1.18.2)
- إذا لم تحدد إصدار، سيحاول البوت اكتشاف الإصدار تلقائياً
